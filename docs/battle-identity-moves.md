# Scene ability moves

Application **0.33.0**, engine **0.26.0-core**, protocol **34**, schema **4**. This batch implements the supplied v3.0 Entrainment, Doodle and Core Enforcer cards, in that order. Exact source effects and source hashes are kept in `rules/identity-moves.json`; supplied cards are unchanged. Shadow Force cross-encounter recovery work is intentionally not scheduled, by user decision on 27 October 2026; its existing encounter-local implementation is unchanged. Wild/training encounters remain separate from the battle engine.

| Move | Executable rule |
| --- | --- |
| Entrainment | Replace the target's ability with the user's current scene ability identity, for the scene. Switching out does not end the assignment. Missing or Unique source abilities cannot pass; protected Unique recipient identities cannot be replaced. |
| Doodle | Copy the target's current scene ability identity onto the user only, for the scene. It does not change allies. Unique/unresolved abilities cannot be copied; protected Unique recipient identities cannot be replaced. |
| Core Enforcer | Ordinary Dragon/Special damage. Its added effect removes the target's ability for the scene only if that exact target dealt positive damage to the user this round. Switching out does not end removal. Unique target abilities remain protected; a Unique user ability does not prevent the move. |

The normal accuracy, reaction, protection, immunity, reflection, decoy, ownership and GM-adjudication paths still apply. Composite ability identities remain explicitly GM-resolvable rather than choosing one silently. Entrainment and Doodle use the existing Role Play/Skill Swap identity model: current scene/Trace/contact/form assignments are copied, not original library identities, and source suppression or negation is not transferred. The recipient remains subject to its own scene negation and ambient Gas. Existing scene negation and Gas suppression remain separate from assignment; copying does not erase them. Replaced Trace/contact-copy overrides are cleared for the affected recipient. Live hooks update to the new ability, and original library sheet abilities are not rewritten. Normal battle end restores the original identity.

Core Enforcer uses recorded damage provenance, not merely whether the target acted. A miss, zero damage, an older round or another attacker does not qualify. Explicitly sourced retaliation, Rocky Helmet, Innards Out, Bad Dreams, draining ticks and Liquid Ooze are recorded with an indirect category; Counter and Mirror Coat continue to use only actual Physical/Special move pools. Item retaliation uses a generic history label so the new ledger does not reveal hidden equipment. Anonymous manual HP corrections and environmental damage without a Pokémon source are not attributed to an opponent. Such narrative cases retain explicit GM effect adjudication.

New encounters snapshot `TurnFlow.identity_moves = true`; historical encounters and omitted flags retain false. Previous battlefield setup and group/item/ability gates remain enabled for their historical engines. Upgrade between battles and use matching clients. Preview notes and temporary ability history explain the selected move and any no-change result.
