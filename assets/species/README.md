# Supplemental species images

These 168 unchanged PNGs fill the exact missing species/form assets reviewed in M4-A01. They are build inputs; catalog generation verifies and copies them into the generated `public/sprites` directory for offline use.

The [registry](../../rules/species-asset-review.json) records each image's exact catalog identity, original filename, source page, source image URL, SHA-256 and dimensions. The [review checklist](../../docs/M4-A01-SPECIES-ASSETS-CHECKLIST.md) records the form decisions and validation.
